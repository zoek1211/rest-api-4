# 인증을 `?actorId` 쿼리 파라미터로 대신한다

4부 연습문제(70~79강)는 로그인/로그아웃을 구현하지 않는다. 대신 액터가 필요한 요청(내 정보, 글·댓글 작성·수정·삭제)은 주소에 `?actorId={회원번호}` 를 붙이고, 서버는 그 번호로 회원을 찾아 액터로 삼는다. `actorId` 가 없거나 존재하지 않는 회원이면 `UnauthenticatedException`(401-1), 액터가 작성자가 아니면 `AccessDeniedException`(403-1).

누구나 다른 회원 번호를 넣어 그 회원 행세를 할 수 있으므로 **보안 수단이 아니라 학습용 대역**이다. 세션·JWT·Spring Security 로 교체할 때는 "요청에서 액터를 얻는 한 곳"(`Rq`)만 바꾸면 되도록, 컨트롤러가 `actorId` 를 직접 다루는 코드는 리팩터링 단계에서 `Rq` 로 모은다. 비밀번호도 같은 이유로 평문 저장한다.
